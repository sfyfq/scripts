# My Curated Scripts

## Tampermonkey
### [SubReddit Cleanser](tampermonkey/subreddit_cleanser.js)
Hide posts from uninteresting subreddits when browsing anonymously. Hides Ads while in it. 

### [Disable Gutter Tap](tampermonkey/disable_gutter_tap.js)
Disable the gutter area of Reddit threads from reacting to taps. Get out of the rest area for our thumb.
